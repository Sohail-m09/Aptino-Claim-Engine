# Failure Analysis

During the initial public-case evaluation, the system achieved 75% decision accuracy (9/12). Three false abstentions were identified and analyzed before the workflow was improved.

## Failure 1 — PUB-003: Unnecessary Prior-Policy Evidence

**Expected Decision:** NOT_ADMISSIBLE
**Initial Decision:** NEEDS_REVIEW

### Root Cause

The Coverage & Exclusion Agent requested previous-policy evidence even though the structured claim explicitly stated that prior insurer continuous coverage was zero.

The system therefore treated an already-established claim fact as missing evidence.

### Improvement

The Coverage Agent was updated to treat explicit structured fields in synthetic claim cases as established facts. When prior insurer continuous coverage is zero and no prior policy is claimed, the system no longer requests unnecessary prior-policy records.

### Result

PUB-003 correctly returned NOT_ADMISSIBLE after the fix.

---

## Failure 2 — PUB-007: Irrelevant Policy Clause Applied

**Expected Decision:** ADMISSIBLE_WITH_LIMITS
**Initial Decision:** NEEDS_REVIEW

### Root Cause

The retrieval pipeline returned a cancer-related definition from another policy context. The Coverage Agent over-applied that clause and requested histological confirmation even though the claim already contained a histopathology report and the investigation focused on hospitalization expense limits.

### Improvement

The Coverage Agent was instructed to apply only policy clauses that are materially relevant to the claim and its investigation task. The Case Analysis Agent was also made task-aware so retrieval queries prioritize the actual decision dimensions.

### Result

PUB-007 correctly returned ADMISSIBLE_WITH_LIMITS after the fix.

---

## Failure 3 — PUB-010: Explicit Continuity Evidence Ignored

**Expected Decision:** ADMISSIBLE
**Initial Decision:** NEEDS_REVIEW

### Root Cause

The claim explicitly stated that previous insurer database and claim history had been received, but the Coverage Agent still requested verification of that same information.

### Improvement

Structured boolean fields and prior-policy fields are now treated as established facts for the synthetic evaluation. The agent is prevented from requesting additional verification for facts already represented explicitly in the input.

### Result

PUB-010 correctly returned ADMISSIBLE after the fix.

---

## Additional Reliability Improvement

Later regression testing showed that some decisions could still vary because investigation queries were partly generated by the LLM.

Two deterministic safeguards were therefore added:

* Experimental treatments always trigger retrieval of the experimental/unproven treatment exclusion.
* Explicitly unknown evidence fields such as hospital registration or medical necessity are converted into decision-blocking missing evidence when applicable.

After these improvements, all 12 supplied public cases and all 5 custom cases produced their expected decisions.
